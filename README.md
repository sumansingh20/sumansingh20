```yaml

```

I design and build systems at the intersection of **security**, **distributed systems**, and **applied AI**. My work spans offensive security tooling, cloud-native infrastructure, distributed data processing, and agentic platforms — always with security and reliability as first-class concerns.

- **Security Engineering** — threat intelligence, incident response, penetration testing, zero-trust architecture
- **Distributed Systems** — fault-tolerant schedulers, scalable data engines, cloud-native compute
- **Full Stack Development** — production web applications with clean, typed architectures
- **Applied AI** — agentic workflows, retrieval-augmented generation, evaluation pipelines
